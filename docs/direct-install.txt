EU4 Unicode Patch @PATCH_RELEASE@
作者：VulonLok
适用：EU4 1.37.5.0 Inca，Windows x64，Windows 10 1903 或更新版本。

安装
1. 退出游戏。若已安装其他加载器，备份游戏目录的 VERSION.dll。
2. 将 ZIP 内全部内容复制到 eu4.exe 所在目录，合并文件夹并覆盖同名文件。
3. 正常从 Steam/启动器启动游戏。中文输入及输入法候选窗默认启用。

正确位置
eu4.exe
VERSION.dll
plugins/eu4_unicode_patch.dll
plugins/eu4_unicode_patch/LICENSE.txt
EU4UnicodePatch.README.txt

不需要运行脚本、编译、复制游戏或安装系统字体。

搜索
外交国家列表与省份查找支持中文、全拼、首字母、部分拼音及混合输入。
例如：法兰西可输入 falanxi、flx 或 法lanxi；拼音大小写、声调和空格不影响匹配。
至少 5 个字母的完整拼音容忍一次输错，例如 falanix；模糊音配置见项目的开发说明。

可选字体
主包使用系统字体，基础图集在游戏加载时生成，不附字体文件或预生成图集。需要补充生僻字时，下载
@FONT_PACKAGE@，同样覆盖进游戏目录后重启。
三个字体文件位于 plugins/eu4_unicode_patch/fonts/，安装后仍优先使用系统字体。
删除 fonts/ 文件夹即可取消可选字库；v0.1.1 留下的字库也按可选字体使用。

旧双字节补丁
本包的加载器跳过 plugins/plugin64.dll、开发探针 eu4_unicode_probe.dll
及旧补丁的自动更新脚本，保留这些旧文件。其他插件仍按 plugins 目录加载。
不要再覆盖回旧 VERSION.dll，否则旧双字节插件可能再次加载，与 Unicode 补丁冲突。

汉化
本包提供编码、字体和输入支持，不附带完整中文翻译。
汉化本地化必须是普通 UTF-8；旧双字节转义汉化需要先迁移。
模组字体按游戏加载顺序保留，支持原版同名覆盖和自定义路径。
缺字动态生成目前用于补丁自身图集。

更新
退出游戏后用新玩家包覆盖同一游戏目录。存档与用户设置保留。旧版留下的基础图集不再使用，字体缓存会自动生成。

卸载
退出游戏，删除 plugins/eu4_unicode_patch.dll、plugins/eu4_unicode_patch/、
gfx/fonts/eu4-unicode/、EU4UnicodePatch.README.txt 和 EU4UnicodePatch.FONTS.txt。
曾备份 VERSION.dll 时恢复备份；若本包是首次安装的加载器，删除本包的 VERSION.dll。
恢复旧加载器后，留下的旧双字节插件及其自动更新会恢复原来的行为。

日志：plugins/eu4_unicode_patch.log
启用标志：UTF-8 import, UI, format, map and bitmap iterators enabled.
Refused 表示版本或冲突检查未通过；缺字或图集已满也记录在日志中。

UI 与地图图集按需分页，均有内存上限；复杂文字整段排版尚未接入。
