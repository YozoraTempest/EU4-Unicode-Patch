## 已发现并处理的问题

1. 本机 version.dll 加载器在 `plugins` 目录不存在时，以 `0xC0000409` 退出。测试准备流程建立该目录后能启动。
2. 字体路径的前缀替换曾生成不存在的 `zh-hans-24s` 等路径。准备脚本现替换完整路径，并保持字体定义的颜色设置。
3. 原始字体中少量 U+0100–U+09FF 字形占用字体对象成员范围。只在私有字体副本中重定位这些 ID。
4. 缺字占位最初覆盖了换行的空字形语义。字形回退现保留 U+0000–U+001F 的控制处理，重新验证了长段落换行。
5. 从高频文字入口卸载 Frida 跟踪代理时，事件日志出现 `frida-agent.dll_unloaded` 访问冲突。正常交互测试改用无 Frida 的启动脚本；跟踪脚本结束时先关闭其专用游戏实例，再释放跟踪会话。

## 未验收能力

颜色与图标格式、地图文本、输入编辑、输入法、搜索、存档自定义文本、联机文本、完整 Unicode 换行、组合字符、字素簇、双向文字和复杂文字 shaping 均未验收。当前字体也不具备完整韩文或非 BMP 字形覆盖。

本记录验证首个普通文本原型，不构成完整发行版或长时间游戏稳定性的证明。
