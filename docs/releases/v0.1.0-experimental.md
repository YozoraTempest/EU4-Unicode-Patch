首个实验版，适用于 **EU4 1.37.5.0 Inca / Windows x64**。使用标准 UTF-8 显示中文和扩展汉字，新增按需字形及中文输入法候选窗修补。

## 功能

- UTF-8 本地化、UI 和地图文字，保留颜色、资源图标及中文换行。
- 思源黑体 SC＋遍黑体 P1/P2，运行时生成未预收录的汉字，解决新输入显示省略号的问题。
- 单行完整提交、整字退格、键盘选区/替换，以及 Windows 中文输入法候选窗显示和定位。
- 外交国家名 Unicode 搜索，中文/扩展汉字路径及存档名称修正。

## 运行

下载 `EU4UnicodePatch-1.37.5-v0.1.0-experimental-isolated.zip`，解压后进入 `EU4UnicodePatch` 文件夹，在 PowerShell 7 运行：

```powershell
$gameDirectory = 'D:\SteamLibrary\steamapps\common\Europa Universalis IV'
.\tools\prepare-runtime.ps1 -GameDirectory $gameDirectory
.\tools\prepare-test.ps1 -GameDirectory $gameDirectory -OpenFonts
.\tools\start-test.ps1 -ExperimentalInput
```

将游戏路径替换为自己的安装目录。需要 Windows 10 1903+、已安装的 EU4，以及原游戏目录中的 x64 [Matanki EU4dll](https://github.com/matanki-saito/EU4dll) `VERSION.dll` 加载器。首次准备复制约 5 GB 游戏资源，使用独立测试模组与用户目录。包内已有 DLL、字体生成器和开源字体，无须编译或安装 Python。

**本版限定在隔离游戏副本运行。** 直接复制到正式游戏目录会被目录保护拒绝；小型测试模组不提供整套汉化。更新与移除见[运行说明](https://github.com/YozoraTempest/EU4-Unicode-Patch/blob/v0.1.0-experimental/docs/install.md)。

## 验证范围

- 当前发布 DLL 通过七个核心测试、两个错误宿主保护检查，以及真实外交搜索框的三个受控完整 SDL 提交；14 个实际 GPU 字形区域逐像素一致，其中 11 个动态新增，包括扩展汉字。
- 所选字库覆盖 Unicode 17 已分配的 102,998 个统一/兼容汉字；这是字符映射覆盖，未逐字验收全部游戏显示。
- 此前候选窗修补版由用户确认候选可见、位置正常，以及中文提交/退格/选择/替换正常；新字库版本的更多字符物理输入仍待复验。
- 早期开发版本另有地图、国家搜索、存档/自动保存和受控剪贴板证据，范围见[测试记录](https://github.com/YozoraTempest/EU4-Unicode-Patch/blob/v0.1.0-experimental/docs/validation.md)。

每字号仍为固定单页。多页/预算、整段复杂排版、其他控件与输入法、游戏长期设备恢复、系统剪贴板完整链路、铁人和多人联机尚未完成；测试模组会改变校验和。
