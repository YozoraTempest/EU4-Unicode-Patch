适用于 **EU4 1.37.5.0 Inca / Windows x64**。

## 更新

- 优先使用玩家系统字体，主包不再附带完整字库。
- 思源黑体 SC 和遍黑体单独提供为可选字体包，补充系统缺少的字形。
- 简化第三方说明。

## 安装

下载 `EU4UnicodePatch-1.37.5-v0.1.2-experimental-drop-in.zip`，退出游戏，备份已有的 `VERSION.dll`，将 ZIP 内全部内容复制到 `eu4.exe` 所在目录，再正常启动。

需要补充字形时，再下载 `EU4UnicodePatch-fonts-v0.1.2-experimental.zip`，同样覆盖进游戏目录后重启。可选字体仅供游戏使用，安装后仍优先使用系统字体。

从 v0.1.1 更新时，原有字库会作为可选字体继续使用；只用系统字体时可删除 `plugins/eu4_unicode_patch/fonts/`。[安装与卸载](https://github.com/YozoraTempest/EU4-Unicode-Patch/blob/v0.1.2-experimental/docs/install.md)

## 兼容性

本包提供 UTF-8 和输入支持，不附带完整汉化。旧双字节转义汉化需要转换成普通 UTF-8。

无字库主包通过游戏启动检查；系统字体和可选字库两种模式通过五种字号的真实 D3D9 像素检查、设备 Reset 和释放检查。[测试记录](https://github.com/YozoraTempest/EU4-Unicode-Patch/blob/v0.1.2-experimental/docs/validation.md)

本版仍为实验版。整套人工输入复验、多页图集、复杂文字排版、铁人和联机仍待完成。
