适用于 **EU4 1.37.5.0 Inca / Windows x64**。

## 更新

- 改为玩家覆盖安装包，支持正常游戏目录，附带加载器、开源字体和预生成图集。
- 默认启用 UTF-8 输入、中文输入法候选窗和单行编辑。
- 运行时补充未预收录的汉字；包内加载器跳过旧双字节插件及其自动更新。

## 安装

退出游戏，备份已有的 `VERSION.dll`，将 `EU4UnicodePatch-1.37.5-v0.1.1-experimental-drop-in.zip` 内全部内容复制到 `eu4.exe` 所在目录，合并文件夹并覆盖同名文件，然后正常启动。

无需脚本、编译、游戏副本或系统字体安装。更新时用新版玩家包覆盖同一目录。[安装与卸载](https://github.com/YozoraTempest/EU4-Unicode-Patch/blob/v0.1.1-experimental/docs/install.md)

## 兼容性

本包提供 UTF-8、字体和输入支持，不附带完整汉化。旧双字节转义汉化需要转换成普通 UTF-8。其他插件仍从 `plugins` 加载，已测试与 MenuPatch 一起启动。

正式 DLL 已在普通目录、原版字体定义下启动，记录了中文及扩展汉字的动态上传；五种字号通过真实 D3D9 字形上传检查。输入和候选窗沿用已有实现，最终玩家版尚未完成整套人工复验。[测试记录](https://github.com/YozoraTempest/EU4-Unicode-Patch/blob/v0.1.1-experimental/docs/validation.md)

本版仍为实验版。多页图集、复杂文字排版、所有控件与输入法、长期战役、铁人和联机仍待完善。
